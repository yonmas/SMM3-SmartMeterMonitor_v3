# アーカイブ理由（2026-08-09）

`smm3_main.py`（無印）・`smm3-lite_main.py`（lite無印）を、Web非対応の正規バージョンから
アーカイブへ降格。

以降、`smm3_main_web.py`／`smm3-lite_main_web.py`が正式版。Web機能はGASのURLを
`config_main.json`で空欄にしておけば自動的に無効化されるため、無印版は実質的に
Web版の下位互換（フリーズ対策等が無い分、機能で劣る）。ユーザー数規模を踏まえ、
「外部通信の完全な構造的排除」を必要とするユーザー層を想定する必要は無いと判断し、
無印版の維持を終了した。
