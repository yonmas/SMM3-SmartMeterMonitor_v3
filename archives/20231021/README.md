# アーカイブ理由（2023-10-21）

親機・子機の履歴データ取得ロジックを見直した際（README.mdお知らせ履歴の2023/10/21項目参照）の、
見直し前バージョンのスナップショット。子機からのリクエストの都度、親機がスマートメーターから
履歴データを取得・転送する方式で、見直し後（親機起動時に取得・保存し、子機へは保存済みデータを
送信する方式）より初期化が大幅に遅かった。

`archives/20260809/`（Web非対応版の降格）とは別の理由によるアーカイブ。こちらは
「ロジック自体が旧式」、`20260809/`は「Web対応版に対して機能で劣る」という違いがある。
